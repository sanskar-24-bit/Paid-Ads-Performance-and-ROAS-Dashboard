Performance Analysis & ROAS Dashboard

This project is an interactive Power BI dashboard designed to analyze paid advertising campaign performance and measure Return on Ad Spend (ROAS). The dashboard provides insights into key marketing metrics such as impressions, clicks, conversions, revenue, ad spend, CTR, CPC, CPA, and overall campaign profitability.

Key Features

- Campaign-wise performance tracking
- ROAS and revenue analysis
- Conversion and customer acquisition insights
- Interactive filters and visualizations
- KPI cards for quick business overview
- Trend analysis for marketing optimization

Tools & Technologies

- Power BI
- Excel / CSV Dataset
- Data Cleaning & Transformation
- DAX Measures

Objective

The main objective of this project is to help businesses evaluate advertising effectiveness, optimize marketing budgets, and make data-driven decisions using visual analytics.
